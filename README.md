# 🍷 VinhApp

O **VinhApp** é um aplicativo de venda de vinhos desenvolvido em **React Native** como projeto acadêmico da disciplina, com foco na aplicação prática de conceitos de desenvolvimento mobile, interface de usuário e organização de produtos para e-commerce.

### Sobre o Projeto
Projeto desenvolvido para fins acadêmicos, simulando uma plataforma de venda de vinhos por meio de um aplicativo mobile, proporcionando a experiência de navegação, visualização e compra de produtos.
